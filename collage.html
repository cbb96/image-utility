    Grid or strip

    A grid arranges every image into equal-sized cells, wrapping to a new row once the column count is reached — good for a contact sheet or a set of product shots. A strip lines images up in a single row or column at a shared height or width, which suits a before-and-after pair or a short sequence read left to right.

    Choosing a fit

    Cover fills every cell with no border, cropping whatever doesn't fit — the safest default when your source images are already similar shapes. Contain guarantees nothing is cropped, at the cost of a border on images that don't match the cell's proportions. Stretch ignores the original aspect ratio entirely, which distorts anything that isn't already the right shape.

    Why the order matters

    Both the grid and the two strip layouts place images in the order they appear in the queue below — left to right, then top to bottom for a grid. Drag any row to reorder it, or use the arrow buttons if you'd rather not drag. The preview updates the next time you build the collage, so you can rearrange freely before committing to a render.

    Why does the grid crop my images by default?

    The default fit is "Fill the cell," which gives the most even-looking grid when your photos are a mix of shapes. Switch to "Show the whole image" if cropping isn't acceptable for your source material.

    Can I use just two images?

    Yes — a two-image grid or strip works the same way as a larger batch, and is a common way to build a quick before-and-after comparison.

    How big is the final image?

    For a grid, roughly columns × cell size wide and rows × cell size tall, plus the gaps. For a strip, the combined width (or height) of every image scaled to the shared cell size, plus gaps.

    Does this tool resize my originals?

    No. Your source files are never modified — the collage is a new image built from copies drawn onto a canvas, the same way every tool on this site works.
