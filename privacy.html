Privacy

Last updated 2026.

Your images

Every tool on this site reads files using the browser's File API and processes them with the Canvas API, entirely inside the page. That means your images are never transmitted to any server operated by this site or anyone else — there is no upload endpoint for a tool to call. You can verify this yourself: open your browser's developer tools, watch the network panel, and run any conversion. Nothing goes out.

A couple of tools use your browser's local IndexedDB storage to carry a file from the homepage to a tool page when you click a "send to" chip (for example, dropping a photo on the homepage and choosing "Convert"). That storage is local to your device, expires automatically after ten minutes, and is never read by anything other than the page you're using.

What this site does collect

The site itself is static hosting with the advertising slots you see between sections. If those advertising slots are active, the provider serving them may set cookies or use similar technology in line with their own privacy policy, independent of anything this site's own code does. Standard web server logs (IP address, user agent, requested page) may be collected by the hosting provider for operational and security purposes, the same as almost any website.

A single preference — your chosen colour theme (light, dark or auto) — is stored in your browser's localStorage so it persists between visits. It never leaves your device.

Third parties

Page fonts are loaded from Google Fonts, which involves your browser making a request to Google's servers for the font files, subject to Google's own privacy policy. No image or file you process is involved in that request.

Changes to this policy

If this policy changes, the date above will update. Because this is a static site with no account system, there's no mailing list to notify — check back here if you want the current version.
