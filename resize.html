    Pixels or percentage

    Pixel mode is for when you know exactly what you need — a 1200×630 social card, an 800×600 thumbnail, a maximum width for a blog post. It sets one target size and applies it to every image in the queue, which is what you want when the output needs to match a spec.

    Percentage mode is relative: each image is scaled against its own original dimensions, so a batch of differently sized photos keeps its differences rather than being forced to a single shape. It's the better choice when you're just shrinking a folder of camera photos for email or a shared drive.

    Why the aspect ratio lock matters

    Setting width and height independently, without locking them together, stretches or squashes the image — circles become ovals, faces get wider or narrower than they should. The lock recalculates the dimension you didn't touch, using the true proportions of the first image you loaded, so the result always matches the original shape unless you deliberately unlock it.

    Choosing a target size

    Resize to the size the image will actually be shown at, not the size your camera happened to produce. A photo displayed at 1200px wide on a web page gains nothing from being shipped at 4000px — it just costs bandwidth and load time. The presets cover the sizes that come up most often: HD and Full HD for screens and video thumbnails, a square crop-friendly size for Instagram, and the 1200×630 shape most social platforms expect for link previews.

    Format is preserved from the source file: a JPEG stays a JPEG, a PNG stays a PNG. If your browser can't re-encode the original format — this happens occasionally with less common formats — the tool falls back to PNG and the downloaded file name reflects that.

    What's the difference between resizing by pixels and by percentage?

    Pixel mode sets an exact target width and height that applies to every image in the batch. Percentage mode scales each image relative to its own original size, so a mixed batch of different-sized photos keeps its relative proportions.

    How do I resize without distorting the image?

    Keep "Lock aspect ratio" checked. Editing the width then recalculates the height (and vice versa) using the original image's true proportions, so the result is never stretched.

    Will resizing make the file smaller?

    Usually, yes, and often dramatically. File size scales with pixel count, so halving both dimensions removes about three quarters of the data before any compression is even applied.

    Can I enlarge a small image?

    The tool will stretch pixels up if you ask it to, but no resizer can invent detail that was never captured, so upscaled photos look softer than a genuinely high-resolution original. Turn on "Don't enlarge smaller images" to skip upscaling automatically across a mixed batch.

    Does resizing change the file format?

    No. Each image is re-encoded back to its own original format. If your browser can't write that format, it falls back to PNG instead, which the file name reflects.
