About Pixelbench

A bench of image tools that run where your files already are: on your own device.

What this is

Pixelbench is a set of small, single-purpose image tools — convert, compress, resize, crop, rotate, watermark, build a PDF, and a handful of others — that all work the same way: you drop a file in, the work happens in your browser using the Canvas and File APIs, and the result downloads straight back to your device. There's no server in the middle doing the processing, no upload progress bar, and no account to create.

Why it's built this way

Most "convert your image" sites upload the file to a server, process it there, and hand back a download link. That's an unnecessary step for work a modern browser can already do on its own — and it means a stranger's server briefly has a copy of whatever you uploaded, whether that's a holiday photo or a scanned document with a name and address on it. Running everything locally removes that step entirely. You can check this yourself: open your browser's network panel, run any tool here, and watch that nothing goes out over the wire.

What it isn't

This isn't a photo editor. There's no layers, no undo history spanning a whole session, no cloud sync of your projects. Each tool does one conversion or adjustment, well, and gets out of the way. If you need something more involved, a dedicated editor is the right tool — Pixelbench is for the smaller, more frequent job of getting one file from the shape it's in to the shape you need right now.

Cost and support

Every tool is free, with no usage limits beyond what your own device's memory can handle. The site is supported by the advertisement slots you'll see between sections — there's no paywall, no premium tier, and no watermark added to anything you create here.
